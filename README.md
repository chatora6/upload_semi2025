# 

## 目的
  　webアプリで必要とされることが多いファイルのアップロードやダウンロードの開発を通して、プログラミング技術の向上と共に、利用者の視点からどのような機能を必要とするのかを学ぶ。このアプリは飲食店で本部がファイルのアップロードを行い、店舗がそのファイルのダウンロードを行うという想定で作成したものである。ここで、アップロードとは、自分のコンピューターにあるファイルやデータを、インターネットを通じてサーバなどのリモートコンピュータに送信することであり、ダウンロードとは、サーバなどのリモートコンピュータから自分のコンピュータにファイルを転送することである。

## 機能要件
  ### 2-1.ログイン機能
    ユーザIDとパスワードを入力でログイン可能。
  ### 2-2.アップロード機能
    ファイルと共にファイルの説明を入力、ジャンルを追加しファイルのアップロードが可能。
    ファイルは最大二つまで同時にアップロード可能。
    アップロード可能なファイルはファイルサイズ20MB以下、種類をpdfのみ。
    アップロード時にファイルの上書き防止のためファイル名に日付をたし、ハッシュ関数を用いて保存される。
  ### 2-3.メニュー機能
    HOME、すべてのファイル一覧、ジャンル別ファイル一覧、ログアウトがある。
    ユーザID「admin」でログインした場合、新規アップロード画面が表示される。
    押下でそれぞれの画面に遷移。
  ### 2-4.ホーム画面機能
    ログイン後表示される画面。メニューからも遷移可能。新着のアップロードされたファイル5つを表示。アップロードされた日付、ジャンル、ファイル説明、確認ボタンを表示する。
  ### 2-5.ファイル一覧機能
    メニューからジャンル別ファイルを一覧または、すべてのファイル一覧画面に遷移可能。ファイル説明、確認ボタン、ジャンル、日付、ダウンロードボタンを表示。ユーザID「admin」でログインした場合、削除ボタンを表示。
  ### 2-6.ファイル削除機能
    ユーザID「admin」でログインした場合一覧画面にてボタンを表示させ、ボタンを押すことでファイルの削除可能。
  ### 2-7.ダウンロード機能
    一覧画面でダウンロードボタンを表示させる。押下でダウンロード可能。ダウンロード時のファイル名はファイル説明と同様。
  ### 2-8.プレビュー機能
    ホーム画面または一覧画面で確認ボタンを表示される。押下することでPDFでファイルを確認可能。
  ### 2-9.並び替え機能
    ファイル一覧画面でファイルがアップロードされた新しい順と古い順で並び替え可能。
  ### 2-10.ログアウト機能
    メニューからログアウト可能。ログイン画面に遷移される。

## 主な開発環境
    VS Codeを使用し、phpで機能を作成する。

## 使い方
    ログイン画面：ユーザID、パスワードを入力してログインボタンを押下。
    
    ホーム画面：確認ボタン押下でファイル確認。
    
    ファイル一覧画面：確認ボタン押下でファイル確認。ダウンロードボタン押下でファイルのダウンロードを行う。新しい順もしくは古い順を選択することでファイルの並び替えを行う。ユーザID「admin」でログインした場合は削除ボタン押下でファイルの削除を行う。
    
    メニュー：文字押下でホーム画面、フォーム画面、一覧画面に遷移する。「ログアウト」を押下でログアウトを行う。
    
    フォーム画面：ユーザID「admin」でログインした場合、20文字以内でファイル説明を入力し、20MB以内のPDFファイルを選択、ジャンルを選択する。2つ同時にファイルをアップロードを行う場合は「もう一つファイルを追加する」を選択した後同様の動作を行う。その後アップロードボタンを押下しファイルのアップロードを行う。
